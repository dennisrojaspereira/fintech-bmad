- (decision) AD-1: Single PostgreSQL database as source-of-truth; no message queues or service stores. Simplifies MVP, enables direct referential integrity.
- (decision) AD-2: Synchronous webhook receiver (no queue); Asaas returns 5xx if DB fails, triggering Asaas retry. Ensures 99.9% delivery.
- (decision) AD-3: Pluggy is daemon-polled every 6h, not real-time webhook. Reduces operational complexity.
- (decision) AD-4: Matching engine is deterministic daemon (5min interval). Creates Conflict rows for manual resolution.
- (decision) AD-5: API server read-only; mutations via webhook/daemon/dashboard only. Single mutation path = consistency.
- (decision) Stack: Node.js + Express + PostgreSQL + cron (no queues, no TS, no SPA). Keep educacional, deployable in 1 VM.
- (event) Architecture spine finalized. 5 core decisions (AD-1 to AD-5), stack defined (Node/Express/PostgreSQL), data model seeded.
